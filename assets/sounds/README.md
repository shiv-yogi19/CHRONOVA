# Audio & Sound Asset Directory

CHRONOVA utilizes the modern **Web Audio API** to synthesize crystal-clear, zero-latency micro-interaction sound effects directly in code:
- Haptic UI button clicks
- Onboarding "Got It" harmonious chords
- Stopwatch lap sound
- Countdown timer dual electronic alarm gong
- Widget swipe swooshes

This guarantees zero broken audio requests, zero loading latency, and 100% offline capability.
