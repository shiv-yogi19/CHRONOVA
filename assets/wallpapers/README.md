# Wallpapers Asset Directory

CHRONOVA includes:
- **12 Dynamic Wallpapers** rendered in real-time via HTML5 Canvas procedural shaders (Cyber Matrix, Neon Horizon, Aurora Borealis, Minimal Void, Deep Ocean Abyss, Golden Celestial, Liquid Lava Glass, Cyberpunk Cityscape, Geometric Prisms, Retro Quartz LED, Cosmic Nebula, Zen Japanese Ink).
- **10 Live Wallpapers** rendered procedurally.
- **Custom Media Storage**: Uploaded personal photos and videos are stored locally inside the browser's IndexedDB storage (`chronova_media_db`), preserving full privacy without uploading to any server.
